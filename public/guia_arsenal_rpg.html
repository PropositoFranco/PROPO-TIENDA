Guía de Personalización

¿Cómo llegas hoy? Elige tu camino.

🎯
Ya sé qué quiero
Tengo claro mis colores, fuentes y textos. Quiero ir directo al Ctrl+F / Ctrl+H.
🎨
Quiero adaptarlo
Quiero entender qué cambiar primero y construir mi propio estilo paso a paso.
Paso 0 — Antes de empezar
0
Prepara tus 3 datos
Antes de abrir VS Code, ten listos estos 3 datos. Son todo lo que necesitas.
// 1. Tu color principal (ej: dorado → cualquier color tuyo)
COLOR_PRINCIPAL: #D4AF37 ← cámbialo por tu color

// 2. Tu nombre de marca o app
NOMBRE_MARCA: "Templo del Propósito" ← tu nombre

// 3. Tu color secundario (ej: púrpura → el tuyo)
COLOR_SECUNDARIO: #7C3AED ← cámbialo
Paso 1 — Colores globales
1
Abre tokens.js — cambia los 3 colores base
Este archivo controla todos los colores de todos los componentes a la vez. Empieza aquí.
Ctrl+F busca esto:
BUSCAR #D4AF37
Ctrl+H reemplaza con:
REEMPLAZAR tu-color-aquí ← ej: #FF6B35
Repite para el color secundario:
#7C3AED → tu-color-secundario
Paso 2 — Por componente
RPGBackground.jsx
Cambia color del portal y densidad de estrellas
▾
Hay 2 cosas que puedes cambiar: el color del portal y cuántas partículas aparecen.
// Color del portal (línea ~45)
rgba(124,58,237, → rgba(TU_COLOR_RGB,

// Cantidad de partículas (línea ~20)
const COUNT = 80 → const COUNT = 60 ← menos = más ligero
RPGButton.jsx
Cambia colores, fuente y texto de hover
▾
El botón primario tiene gradiente dorado y el ghost tiene borde. Ambos se controlan con Ctrl+F.
// Gradiente del botón primario
from-gold to- → from-[tu-color] to-

// Texto del botón ghost
text-gold border-gold → text-[tu-color] border-[tu-color]
RPGInput.jsx
Cambia el color del aura al enfocar
▾
El input brilla cuando el usuario hace clic en él. Ese brillo es ajustable con un Ctrl+H.
// Aura al enfocar (focus glow)
rgba(212,175,55,0.07) → rgba(TU_R,TU_G,TU_B,0.07)

// Color del borde al enfocar
focus:border-gold/60 → focus:border-[tu-color]/60
RPGPanel.jsx
Cambia shimmer, esquinas y glow
▾
El panel tiene 3 efectos: línea shimmer, esquinas decorativas y brillo de fondo. Se pueden cambiar de color individualmente.
// Shimmer (línea top e inferior)
via-gold/50 → via-[tu-color]/50

// Esquinas ornamentales
border-gold/50 → border-[tu-color]/50
LevelUpCinematic.jsx
Cambia el texto y el color de rayos
▾
Tiene 2 props que puedes cambiar directamente cuando lo uses: el número de nivel y el texto. También puedes cambiar el color de los rayos.
// Cómo lo usas en tu app:
<LevelUpCinematic
  show={mostrar}
  level={nivelActual} ← número
  onComplete={() => setMostrar(false)}
/>

// Color de los rayos dentro del archivo:
rgba(212,175,55, → rgba(TU_R,TU_G,TU_B,
UnlockCinematic.jsx
Cambia el color del crystal y el texto
▾
El crystal acepta un color por prop. Puedes pasarle cualquier color hex y automáticamente tiñe el glow.
// Cómo lo usas:
<UnlockCinematic
  show={mostrar}
  color="#8b5cf6" ← tu color hex
  title="¡Logro Desbloqueado!"
  onComplete={() => setMostrar(false)}
/>
Paso 0 — Define tu identidad visual
0
Antes de tocar código: define 4 cosas
No necesitas saber programar. Solo necesitas tener claro 4 decisiones. Puedes anotarlas aquí en papel antes de abrir VS Code.
Pregunta 1: ¿Cuál es tu color principal?
→ Puede ser el de tu logo, tu marca, lo que más te guste.
→ Busca "hex color picker" en Google para encontrar el código.

Pregunta 2: ¿Cuál es tu color de acento/contraste?
→ Un color que complemente al principal. Ej: si tienes azul, acento naranja.

Pregunta 3: ¿Cómo se llama tu app o plataforma?
→ Ese nombre reemplazará "Templo del Propósito" donde aparezca.

Pregunta 4: ¿Qué estilo de fondo quieres?
→ Oscuro (como está), Claro, o Neutro (gris).
Paso 1 — Empieza por tokens.js
1
Abre tokens.js primero — es el "cerebro" de los colores
Este archivo tiene todos los colores en un solo lugar. Si cambias algo aquí, cambia en todos los componentes automáticamente. Es lo primero que debes tocar.
// En VS Code: Archivo → Abrir carpeta → elige la carpeta descargada
// Busca tokens.js en el panel izquierdo y haz doble clic

// Verás algo así:
export const COLORS = {
  gold: '#D4AF37', ← tu color principal
  purple: '#7C3AED', ← tu color secundario
  dark: '#0A0812', ← fondo oscuro
  text: '#E8DFC0', ← color del texto
}
Ctrl+H en tokens.js:
'#D4AF37' → 'tu-color-principal'
'#7C3AED' → 'tu-color-secundario'
Paso 2 — Texto y nombre de tu marca
2
Cambia los textos que digan "Templo del Propósito"
En algunos componentes hay textos de ejemplo. Búscalos con Ctrl+F y reemplázalos con el nombre de tu app o deja los tuyos.
Ctrl+H en cada archivo:
Templo del Propósito → Tu Nombre Aquí
Templario → Como llamas a tus usuarios
Tip: Si en tu app los usuarios se llaman "Agentes", "Guerreros" o algo diferente, reemplaza "Templario" por eso.
Paso 3 — Prueba en tu proyecto
3
Copia los archivos a tu proyecto y pruébalos
Una vez que tengas los colores cambiados en tokens.js, copia los archivos .jsx a la carpeta de componentes de tu proyecto. Luego impórtalos así:
// En cualquier página de tu app, arriba del todo:
import RPGButton from './components/RPGButton'
import RPGPanel from './components/RPGPanel'

// Luego úsalos como si fueran palabras HTML:
<RPGPanel title="Bienvenido">
  <RPGButton>Entrar</RPGButton>
</RPGPanel>
¿Algo no se ve bien?
Cada componente tiene comentarios arriba explicando qué hace cada parte. Busca con Ctrl+F el color o texto que no te guste y reemplázalo.
